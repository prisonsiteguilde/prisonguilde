## 1. Концепция и видение

**TON Abyss** — это мобильный turn-based рогалик, где игрок спускается всё глубже в многоуровневую Бездну, собирает **хардкорно добытый лут**, крафтит снаряжение, приручает питомцев и бьётся с многофазными боссами. Ключевая мантра дизайна:

> **«Каждый предмет — событие.»**

В мобильных ARPG и клик-играх эпик выпадает каждые 5 минут и превращается в мусор. В TON Abyss редкости (rare → abyssal) выпадают с резко убывающей вероятностью, а смерть в хардкоре отбирает золото и прогресс. Это делает каждый удачный дроп и каждое удачное усиление эмоциональным якорем — кор-петлёй долгосрочного удержания.

### Столпы дизайна
1. **Реальная ценность лута** — редкие дропы действительно редкие, но любые дропы полезны (распыление, продажа, апгрейд-корм).
2. **Рискованная прогрессия** — усиление +10+ уничтожает предметы, хардкор-смерть хоронит персонажа.
3. **Глубокая прокачка без pay-to-win** — стата/аффикс/класс/питомец/руны — всё через игру.
4. **Быстрые сессии (2–6 минут данж)**, с глубокой мета-игрой между ними.
5. **Децентрализованная интеграция** — кошелёк TON для премиум-косметики и NFT-питомцев мифического+ ранга, но без повышения боевой мощи.

## 2. Целевая аудитория и фантазия игрока

- Core: фанаты **Path of Exile / Diablo / Last Epoch / Soulslike roguelites (Hades, Dead Cells)** — 18–35 лет, мобильный + Telegram юзер.
- Вторичная: **TON-комьюнити** — ищут on-chain игры с реальными механиками, а не фарм-таппер.
- Фантазия: «Я спускаюсь в бесконечный колодец ужасов, выживаю вопреки шансам, и каждая победа кованно моя.»

## 3. Игровой цикл

### Микро-цикл (2–6 минут)
```
Выбрать данж → зайти → комната за комнатой (6-20) → босс →
  добыча → (смерть или победа) → вернуться в город
```

### Мезо-цикл (10–40 минут)
```
Несколько данжей → экипировать новое → крафт/усилить → продать/распылить
→ распределить очки характеристик → выбрать следующую сложность
```

### Макро-цикл (дни/недели)
```
Пройти 4 биома → разблокировать новые данжи (кошмар/бездна) →
собрать мифический сет → попытаться на апекс-босса (Титан Бездны) →
Battle Pass / сезонная лидерборд
```

## 5. Характеристики и производные

### Первичные
- **Сила (STR)** — атака, HP, толкание блока.
- **Ловкость (AGI)** — крит.шанс, уклонение, точность, скорость.
- **Интеллект (INT)** — сила заклинаний, мана, шанс пробить сопротивления.
- **Выносливость (VIT)** — HP, защита.
- **Дух (SPI)** — мана, регенерация, сопротивление магии.
- **Удача (LUCK)** — магнит найти, крит-множитель, бонусы дропа.

### Производные формулы
Подробно см. <ref_file file="/home/ubuntu/repos/prisonguilde/ton-abyss/packages/shared/src/formulas.ts" />:

```
maxHp      = 40 + VIT * 9 + STR * 1.2
maxMana    = 20 + INT * 5 + SPI * 3
attack     = STR * 1.5 + AGI * 0.6
spellPower = INT * 1.6 + SPI * 0.5
defense    = VIT * 0.8 + STR * 0.2
critChance = 3%  + AGI * 0.25% + LUCK * 0.3%
critMult   = 1.5x + LUCK * 0.5%
dodge      = AGI * 0.2% (cap 50%)
accuracy   = 95% + AGI * 0.1%
speed      = AGI * 0.5
```

Плюс классовые модификаторы (Страж +6 защита, +5% блок; Зовущий +6 сила заклинаний, +10% сопр. Бездне; и т.д.)

## 6. Формулы боя

Все бои — **детерминистичные, turn-based, seed-based**. Сервер хранит seed и воспроизводимо симулирует бой, клиент только визуализирует. Реализация: <ref_file file="/home/ubuntu/repos/prisonguilde/ton-abyss/packages/shared/src/combat.ts" />.

### Порядок ходов
Актёры сортируются по `speed + jitter(-2..+2)` в начале каждого раунда.

### Формула урона
```
base       = ability.baseDamage + attack * attack_scale + spellPower * sp_scale
dmgAfterRes= base * (1 - resistance[element])
dmgAfterDef= dmgAfterRes * (1 - mitigation)
  where mitigation = defense / (defense + 50 + attackerLevel * 12), capped at 0.75
dmg        = dmgAfterDef * random(0.94..1.06)
if crit:    dmg *= critMultiplier     (roll: critChance)
if blocked: dmg = max(0, dmg - blockAmount)  (roll: blockChance)
```

### Точность/уклонение
```
hitChance = accuracy - dodge   (min 10%)
roll: rng.chance(hitChance)    → иначе промах
```

### Лайфстил
`heal = dmgDealt * lifesteal`, cap 30%.

### Крит-цепочки
Крит не может случиться на атаках, где `canCrit=false` (некоторые AoE, DoT).

### Тайм-аут
Если бой не закончился за 60 ходов — победа по %HP.

### Пример (ур.5 Страж vs ур.3 Скелет)
- Страж: attack=28, crit=7%, crit×1.53, defense=17.
- Скелет: maxHp=60, attack=10, defense=5.
- Урон игрока по скелету: `28 * rand(0.85..1.15) * (1 - 5/(5+50+3*12)) ≈ 28 * 1 * 0.94 ≈ 26` → скелет ~3 хода до смерти.
- Урон скелета по стражу: `10 * (1 - 17/(17 + 50 + 5*12)) ≈ 10 * 0.87 ≈ 8-9`.

## 8. Редкости и лут

Семь редкостей. Базовые веса (до магнит-к-найти, MF):

| Редкость | Вес | Цвет | Аффиксов |
|---|---|---|---|
| Common (обычное) | 1000 | серый | 0–1 |
| Uncommon (нечастое) | 300 | зелёный | 1–2 |
| Rare (редкое) | 90 | синий | 2–3 |
| Epic (эпическое) | 22 | фиолет | 3–4 |
| Legendary (легендарное) | 5 | золотой | 4–5 |
| Mythic (мифическое) | 0.8 | красный | 5–6 |
| **Abyssal (бездонное)** | 0.07 | бирюза | 6–7 + коррупция |

Распределение рассчитывается per-drop от таблиц лута монстра/босса. MF применяется с **soft-cap-кривой** `softMF = 1 - exp(-MF/100 * 0.6)` и усиливает высокие ранги мультипликативно. Источник: <ref_file file="/home/ubuntu/repos/prisonguilde/ton-abyss/packages/shared/src/rarity.ts" />.

### Почему это хардкор
- На 100% MF вероятность Abyssal всё ещё ≈ 0.3% от общего веса дропа, и только от апекс-боссов.
- Эпики до 20 уровня выпадают примерно 1 раз за 40 монстров. Легендарки — 1 раз за ~180.
- Мифик+ практически всегда из боссов, а не из мобов.

## 11. Крафт, усиление, распыление

### Крафт
Рецепты открываются по **default / drop / quest / reputation**. Привязаны к **станкам T1–T5**.

| Станок | Где | Открывает |
|---|---|---|
| T1 | Старт | базовые рецепты кожи/железа |
| T2 | По квесту в Заброшенном склепе | сталь, рунные тканевые |
| T3 | Репутация «Морозный рынок» L3 | мифрил, зачарование |
| T4 | Мифическая руна | Void-крафт |
| T5 | Апекс-Titan-трофей | Abyssal-крафт |

Пример рецепта (клинок Бездны):
```
6×Адамант + 8×Осколка Бездны + 3×Души боссов + 2×Пера феникса + 65 000 золота
→ клинок Бездны ур. 42
Rarity-bias: epic 400 / legendary 300 / mythic 60 / abyssal 4
```

### Усиление (+1..+15)
Таблица успеха/разрушения — <ref_file file="/home/ubuntu/repos/prisonguilde/ton-abyss/packages/shared/src/crafting.ts" lines="18-37" />:

| +N | Успех | Разрушение | Золото | Пыль |
|---|---|---|---|---|
| +1 | 100% | 0% | 100 | 0 |
| +5 | 85% | 0% | 2 000 | 2 |
| +8 | 55% | 18% | 11 000 | 12 |
| +10 | 35% | 32% | 30 000 | 32 |
| +12 | 22% | 48% | 90 000 | 85 |
| +15 | 9% | 65% | 440 000 | 380 |

Каждый уровень усиления = **+4% к эффективным характеристикам предмета**, кумулятивно.

### Распыление (salvage)
Таблица: `common→1 материал, uncommon→2, rare→4+1 пыль, epic→8+3+1 шард, legendary→16+8+3, mythic→32+18+9, abyssal→64+40+22`.

### Стратегические сломы и фичи
- **Коррупция Abyssal**: у каждого Abyssal-предмета есть стат `corruption 1..5`. Коррупция 5 блокирует продажу/перекат, но даёт скрытый мифический бонус. Игрок решает: играть осторожно или рисковать на +15.
- **Реставрация**: раз в неделю можно восстановить случайно уничтоженный +15 предмет ценой 5 душ боссов + 2 TON Stars.

## 13. Боссы и фазы

Каждый босс **многофазный** (пороги HP). При переходе:
- новый набор способностей добавляется;
- возможен баф на атаку/скорость/крит;
- триггерится скриптовый каст (в v0.2).

**MVP-боссы**:

| ID | Имя | Биом | Лв | Фазы | Уникальные дропы |
|---|---|---|---|---|---|
| boss_crypt_lord | Лорд склепа | crypt | 8 | 2 | off_kite_shield, wpn_crypt_dagger, egg_shade |
| boss_ice_matriarch | Матриарх льда | ice | 16 | 2 | arm_plate_legs, wpn_tempest_bow |
| boss_infernal_prince | Принц Преисподней | infernal | 22 | 2 | wpn_abyssal_edge, off_abyss_orb |
| **boss_abyss_titan** | **Титан Бездны** | abyss | 35 | 3 + enrage | ВСЕ Abyss-сетовые |

Enrage: на 40-м ходу босс начинает наносить ×2 урон.

### Пример фазы (Титан Бездны, ~10% HP)
```

```

### Roadmap-боссы (v1.0)
16 уникальных боссов (4 на биом × 4 биома), 4 «сезонных» апекс-босса с NFT-дропом.

## 14. Питомцы

- **6 семейств**: wyrm, golem, spirit, beast, construct, abyssal.

## 16. Экономика и прогрессия

### XP-кривая (<ref_file file="/home/ubuntu/repos/prisonguilde/ton-abyss/packages/shared/src/progression.ts" />)
```
xpForLevel(L) = 60 * L^2 + 3.6 * L^2.6 + 40 * L
```
Примерные тайминги (75% runs victory, core loop):
- Ур.10 ≈ 40 минут.
- Ур.20 ≈ 3 часа.
- Ур.50 ≈ 25–40 часов.
- Ур.100 (cap MVP): 200+ часов.

### Валюты
| Валюта | Источник | Сток |
|---|---|---|
| **Gold (золото)** | любые враги, квесты, продажа | крафт, усиление, вход в данжи |
| **Shards (шарды)** | распыление rare+ | перекат аффиксов, премиум-респек |
| **Abyss Dust (пыль Бездны)** | распыление epic+, боссы | усиление +4+ |
| **TON Stars** (премиум) | TON Connect / Telegram Stars | косметика, Battle Pass, слоты хранилища |

### Sinks (чтобы не копилось)
- **Войти в Бездну**: 10 000 золота + ключ.
- **Усиление +15**: 440 000 золота + 380 пыли.
- **Крафт клинка Бездны**: 65 000 золота + кучи материалов.

### Каталог расходов по уровням (таргет хардкор)

## 17. Хардкорный режим и смерть

В **non-hardcore** режиме смерть = -15% текущего XP уровня + -25% золота + -40% прочности экипировки.

В **hardcore**:
- Персонаж **умирает навсегда**.
- Экипировка перемещается на «кладбище», где её можно откопать **через 72 часа** (или 2 TON Stars сразу).
- Рейтинг глубины сохраняется в лидерборде.
- **Permadeath leaderboard**: топ-100 глубочайших забегов за сезон получают NFT-трофеи.

## 18. TON-интеграция и монетизация

### TON Connect
- Привязка кошелька добровольная.
- Премиум-фичи, покупаемые за TON:
  - **Battle Pass** (1.5 TON, 60 дней) → +1 слот питомцев, косметика, QoL автодобивание, +1 бесплатный респек/день.
  - **Расширение хранилища** (+20 слотов за 0.3 TON, стакается до +200).
  - **Эксклюзивные косметические скины** (0.1–2 TON).
  - **Mythic+ pet NFT mint** (2500 пыли Бездны → NFT в кошельке).

**Ни одна TON-покупка не даёт боевого преимущества.** Это — красная линия дизайна. Слоты хранилища — QoL, а не стата.

### NFT-экосистема
- Питомцы mythic+ минтятся как on-chain TEP-62 коллекции.
- Владение NFT даёт **косметический** скин питомца + аватар в Telegram.
- Secondary market: игрок может продать питомца другому игроку на TON marketplace.

### Telegram Stars
Альтернативная оплата для тех, у кого нет TON-кошелька. Цены аналогичны по стоимости.

## 20. Техническая архитектура

### Монорепо (pnpm workspaces)
```
ton-abyss/
├── apps/
│   ├── web/                React + Vite + Tailwind + Framer Motion + TonConnect
│   └── api/                Fastify + SQLite (Prisma-ready)
├── packages/
│   ├── shared/             Типы, формулы, RNG, экономика

└── docs/
    └── GDD.md              этот документ
```

### Клиент
- **React 18** + **TypeScript strict** + **Vite**.
- **Zustand + persist** — локальное состояние сохраняется в Telegram localStorage. Полноценный демо-режим без бэкенда.
- **TonConnect UI** — стандартный кошелёк-коннектор.
- **PixiJS** (v0.2) — боевые сцены.

### Сервер
- **Fastify** + **better-sqlite3** (миграция на Postgres — одна строчка).
- **Telegram initData** верификация через HMAC-SHA256 (`auth.ts`).
- Эндпоинты: `/api/auth/telegram`, `/api/state`, `/api/character`, `/api/dungeon/run`, `/api/craft`, `/api/upgrade`, `/api/salvage`, `/api/shop/sell`.
- Все боевые расчёты **на сервере**, клиент только визуализирует логи.

### Shared package
Единая точка правды для формул. И клиент, и сервер импортируют одни и те же функции — нет расхождений по балансу.

## 21. Античит и безопасность

### Серверные гарантии
1. **Все бои симулируются на сервере** с сохранённым seed.
2. **Инвентарь — append-only лог транзакций** (v0.3 в Postgres с аудитом).
3. **Крафт/усиление/перекат** — только через API, клиент не может сам выдать себе лут.
4. **Cooldown-чек**: нельзя зайти в данж чаще, чем позволяет `dungeon.cooldownSeconds`.
5. **Лимит «дневных забегов»** (`ECONOMY.DAILY_FREE_RUNS = 5`).

### Клиент: демо-режим
В MVP/preview клиент работает **офлайн на localStorage** для удобства демонстрации. В проде демо-режим отключается флагом `VITE_ONLINE=true`, и все мутации идут через API.

### TON-транзакции
Премиум-покупки проверяются через TON-индексер (TonAPI) после подтверждения on-chain. Клиент никогда не «кредитует» сам себя.

## 24. Риски и допущения

### Риски
1. **Хардкор отталкивает казуалов**. Митигация: non-hardcore режим по умолчанию, хардкор = opt-in за трофеи.
2. **Турнобаз на мобилке может казаться медленным**. Митигация: быстрый лог (200ms/строка), «пропустить» кнопка, 2-3 мин бой максимум.
3. **Telegram Mini App политика**. Митигация: никаких азартных механик за реальные деньги; все премиум-покупки косметические.
4. **TON-комьюнити переоценка on-chain**. Митигация: кошелёк и NFT — опциональны. Игра без кошелька полноценно играбельна.
5. **Экономическая инфляция золота**. Митигация: сиюминутные сливы (+15 усиление, крафт высших ранжей, ключи Бездны) плюс плановое снижение золота с мобов.
